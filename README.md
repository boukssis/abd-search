# ABD Search

Premium one-page website for ABD Search — a founder-led boutique recruitment partner specialising exclusively in rare disease and orphan drug talent.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Motion for React
- Lucide icons

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Brand

Visual identity is derived from the ABD Search logo palette (deep forest green, clean neutrals, restrained editorial typography).
